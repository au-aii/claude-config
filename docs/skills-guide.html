How skills work

スキルの使い方

スキルは Claude が特定の作業(PRD作成・設計書作成など)に入ったときだけ自動で読み込む、 plugins/dev/skills/ 配下の詳細ガイドです。手動で起動する場面は基本的にありません。

起動のしくみ

自動

各スキルの description と今の作業内容が一致すると、Claude が該当スキルを自動で読み込む。/setup-project や /add-feature の中で暗黙に呼ばれるのはこのパターン。

明示

「PRDスキルを使って」のように直接依頼すれば、そのタイミングで読み込ませることもできる。判断に迷ったら明示してよい。

07

ステアリングsteering

6つの永続ドキュメントとは別枠。個々の作業指示ごとに requirements / design / tasklist を記録し、進捗管理する。/add-feature や /setup-steering から自動で読み込まれる。

トリガー
作業計画時 / 実装時 / 検証時
ツール
Read, Write, Edit
出力
.steering/YYYYMMDD-<title>/*.md
スキル本体は plugins/dev/skills/<name>/SKILL.md に生成物として配置されている。 正本は claude-dotfiles — 直接編集せずそちらを更新して再生成する。
